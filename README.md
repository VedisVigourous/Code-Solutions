## Overview

This repository collects solutions across platforms like HackerRank and CodeChef. Each folder mirrors the platform or track, and each file contains a single solution focused on clarity and correctness.

**Highlights**
- Small, focused files for quick lookup.
- Consistent naming aligned with problem titles.
- Clean I/O handling and correct formatting.
