## 📅 30 Days of Code

The [30_Days_of_Code](HackerRank/30_Days_of_Code/) folder is a concise Java practice series built around one file per day. Instead of treating it like a code dump, this track works as a progressive learning path with these characteristics:

- 🧱 Covers fundamentals from input/output, conditionals, loops, and arrays.
- 🔄 Gradually moves into OOP, inheritance, abstract classes, and interfaces.
- 🧮 Introduces collections, recursion, searching, sorting, and string handling.
- 🧰 Uses a consistent file pattern so every day is easy to locate and run.
- ✅ Each solution is self-contained, making it useful for revision and quick review.
- 🎯 Best used as a compact Java bootcamp for strengthening core problem-solving habits.

### What to expect

- Day files follow the pattern `Day_00.java` through `Day_29.java`.
- Most solutions are written to be readable first, then optimized for correctness and clarity.
- Many files are suitable for direct compile-and-run testing with standard input.
- The folder is best understood as a learning sequence, not just a list of individual answers.

## 🧰 Java Stack

- Language: Java 8+ friendly solutions.
- Core topics: I/O, strings, numbers, control flow, and basic formatting.
- DSA coverage: arrays, recursion, collections, searching, sorting, and simple data structures.
- Style: short explanations, clean naming, and practical edge-case awareness.

## ⚙️ How To Run

1. Open the problem on the respective website, such as HackerRank or CodeChef.
2. Open the matching solution file in this repo.
3. Copy the code and paste it into the online editor.
4. Run the sample input first, then submit when everything looks good.

Notes:

- This repo is meant for quick copy-paste usage on the platform pages.
- File names mirror the original challenge structure to make matching easier.
